## 💻 Featured Project

### 🏷️ Data Labeling Management System

A web-based platform for managing dataset annotation workflows with multiple roles:

- Manager: create datasets, labels, projects, assign annotators/reviewers
- Annotator: label data items and submit tasks
- Reviewer: review sampled annotations based on sample rate
- Admin: manage users, activities and system statistics

**Tech:** ReactJS, Axios, MUI, NodeJS, REST API
