## 💻 Featured Project

### 🏷️ Data Labeling Management System

A web-based platform for managing dataset annotation workflow with multiple roles.

<table>
  <tr>
    <td><b>Manager</b></td>
    <td>Create datasets, labels, projects and assign annotators/reviewers</td>
  </tr>
  <tr>
    <td><b>Annotator</b></td>
    <td>Label data items and submit annotation tasks</td>
  </tr>
  <tr>
    <td><b>Reviewer</b></td>
    <td>Review sampled annotations based on sample rate</td>
  </tr>
  <tr>
    <td><b>Admin</b></td>
    <td>Manage users, activities and system statistics</td>
  </tr>
</table>

**Tech Stack:** `ReactJS` `Axios` `MUI` `NodeJS` `REST API`
